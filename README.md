# e-plantShopping

## Paradise Nursery Shopping Application

This project is a React and Redux-based shopping cart application for an online plant shop called Paradise Nursery.

## Features

- Landing page with a button linking to the product listing page
- Navigation bar with links to Home, Products, and Cart
- Product listing page with different plant categories
- Add to Cart functionality using Redux
- Shopping cart page with:
  - Increase quantity
  - Decrease quantity
  - Delete item
  - Total cost calculation
- Continue Shopping and Checkout buttons

## Technologies Used

- React
- Redux Toolkit
- React Router
- CSS
- Vite
